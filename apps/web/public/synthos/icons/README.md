# Tool icons

The GitHub, 1Password, n8n, Obsidian and Mermaid SVG marks are copied unchanged
from [Simple Icons](https://github.com/simple-icons/simple-icons) commit
`4d29a35c954699b389a834aacc97dd6e7e74143c`, files `icons/<id>.svg`.
Simple Icons distributes these files under CC0; the full license is included.
Brand names and trademarks remain their respective owners' property.
The dock renders these monochrome assets with CSS masks; no external assets
are requested at runtime.

All other small tool symbols in `web/tools.js` are original GCH purpose icons,
not official brand logos. Each is paired with the actual tool name and status.
The inspector identifies whether an icon is a brand mark or a GCH purpose icon.
