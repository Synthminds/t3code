# Local font assets

Sora and Montserrat are distributed under the SIL Open Font License 1.1.

- Sora Latin variable WOFF2: `@fontsource-variable/sora` 5.2.6, retrieved from the jsDelivr npm CDN. Source: <https://github.com/sora-xor/sora-font>.
- Montserrat Latin variable WOFF2: `@fontsource-variable/montserrat` 5.2.6, retrieved from the jsDelivr npm CDN. Source: <https://github.com/JulietaUla/Montserrat>.

The cockpit serves these assets locally. It does not request fonts from an external service at runtime.

## Orbitron

Orbitron by The League of Moveable Type is used for the Midnight Protocol display accents.
Self-hosted Latin variable WOFF2 (400–900), retrieved from Google Fonts v35:
https://fonts.gstatic.com/s/orbitron/v35/yMJRMIlzdpvBhQQL_Qq7dy0.woff2

Licensed under SIL Open Font License 1.1; see `Orbitron-OFL.txt`.
The Synthminds wordmark retains Montserrat.
